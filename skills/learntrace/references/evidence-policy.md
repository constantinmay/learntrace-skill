# Evidence policy

## Observable fact

Use only information directly traceable to Git metadata, a project document, an existing test log, or an explicitly authorized trace record. Include one or more source references.

## Student confirmation

Use when the student confirms, corrects, supplements, or denies a candidate learning node. Preserve the distinction between the original candidate and the student's statement.

## Candidate inference

State the supporting observations and uncertainty. Present the inference as a question or candidate explanation until the student confirms it. Never promote it to a learning conclusion automatically.

## Missing evidence

Write `未记录` when a required source or event is absent. Do not invent events, reconstruct full conversations from command summaries, or infer AI use when no authorized trace exists.
